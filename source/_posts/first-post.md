欢迎来到我的个人博客 🎉

这里是第一篇文章。这个博客使用 **Hexo** 搭建，主题是 **Butterfly**，之后会在这里记录：

- 技术笔记与踩坑记录
- 生活随笔
- 一些值得留存的想法

## 怎么发新文章

在 `~/blog` 目录下运行：

```bash
pnpm exec hexo new post "文章标题"
```

然后在 `source/_posts/` 里找到生成的 Markdown 文件，用任意编辑器写内容，保存后本地预览会自动刷新。

## 常用命令

```bash
# 启动本地预览（http://localhost:4000）
pnpm exec hexo server

# 生成静态文件
pnpm exec hexo generate

# 清理缓存
pnpm exec hexo clean
```

这是起点，慢慢写就好。
